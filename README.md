# Сон — демо

Демонстрация дизайна и идеи личного приложения для режима сна и дневника осознанных сновидений.
Открыть: https://danilfadeevfd.github.io/sleep-tracker-demo/

Данные выдуманные и живут только в вашем браузере: после перезагрузки страницы всё возвращается к исходному виду.
Ночная запись сна голосом в демо выключена.
